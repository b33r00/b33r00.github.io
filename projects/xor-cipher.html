XOR Cipher Study

project cryptography python 2026

motivation

I wanted to understand concretely why XOR encryption is considered weak. XOR ciphers appear in beginner CTF challenges and small programs because they are easy to implement, but they are also easy to break if the implementation is not careful. This project was not about building a strong cryptographic system — it was about studying how an attacker recovers the key and decrypts the message using basic mathematical properties.

how XOR encryption works

The XOR cipher encrypts data one byte at a time using the XOR operation:

C = P ⊕ K

Where P is plaintext, K is the key, C is the ciphertext, and ⊕ is XOR. The critical property of XOR is:

A ⊕ B ⊕ B = A

Which means we can rearrange the encryption formula to recover the key:

K = C ⊕ P

If an attacker knows or can guess any part of the plaintext, they can recover the key directly from that segment of ciphertext. No brute force needed.

what this project implements

Three scenarios that appear frequently in CTF challenges and beginner cryptography exercises:

  • Key recovery when plaintext is known (or partially guessable)
  • Detecting repeating XOR keys using index of coincidence
  • Breaking single-byte XOR using English letter frequency analysis

implementation

from collections import Counter
import string

def xor_bytes(data: bytes, key: bytes) -> bytes:
    return bytes(data[i] ^ key[i % len(key)] for i in range(len(data)))

def recover_key_from_known_plaintext(ciphertext: bytes, plaintext: bytes) -> bytes:
    if len(ciphertext) != len(plaintext):
        raise ValueError("Ciphertext and plaintext must have same length.")
    return bytes(c ^ p for c, p in zip(ciphertext, plaintext))

def english_score(text: bytes) -> int:
    common = b" etaoinshrdlu"
    score = 0
    for byte in text.lower():
        if byte in common:
            score += 1
    return score

def break_single_byte_xor(ciphertext: bytes):
    best_score = 0
    best_key = None
    best_plaintext = None

    for key in range(256):
        decrypted = bytes(c ^ key for c in ciphertext)
        score = english_score(decrypted)

        if score > best_score:
            best_score = score
            best_key = key
            best_plaintext = decrypted

    return best_key, best_plaintext

example usage

Recovering the key from known plaintext:

ciphertext = b'\x1f\x04\x0c'
plaintext  = b'cat'

key = recover_key_from_known_plaintext(ciphertext, plaintext)
print("Recovered key:", key)

Breaking single-byte XOR with frequency analysis — this is a classic Cryptopals challenge:

cipher = bytes.fromhex("1b37373331363f78151b7f2b783431333d78397828372d36")

key, plaintext = break_single_byte_xor(cipher)

print("Recovered key:", key)
print("Decrypted message:", plaintext)
The frequency scoring function is intentionally minimal. For real-world use, scoring against full English letter frequencies (a–z weighted) performs better than a simple character membership check.

why this matters

Single-byte XOR is trivially broken by trying all 256 possible keys and scoring the output — 256 trials. Repeating-key XOR (Vigenère-style) can be broken by finding the key length via index of coincidence, then reducing the problem to N independent single-byte XOR problems.

The underlying lesson: XOR is a symmetric, invertible operation with no diffusion. Without a secure key derivation, key stretching, and proper authentication, anything built on raw XOR is fragile. This is why CTF challenges keep using it — and why modern symmetric ciphers (AES-GCM, ChaCha20-Poly1305) layer XOR with substitutions, permutations, and authentication tags on top.
