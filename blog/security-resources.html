Security Learning Resources

blog resources 2026

A curated list of platforms, references, and tools I have found genuinely useful. No affiliate links, no filler. Organized by topic.

methodology / cheat sheets

  • pentesting.siteFull kill chain walkthrough from recon to post-exploitation, broken down by port and service. Cheat sheets for 18 tools including nmap, ffuf, BloodHound, Impacket, NetExec, Mimikatz, hashcat. Actively maintained.
  • payloads.sitePayload collection companion to pentesting.site, from the same author.
  • book.hacktricks.xyzComprehensive pentesting wiki covering privilege escalation, Active Directory attacks, web vulnerabilities, and more. One of the most referenced field guides.
  • gowthams.gitbook.io/bughunter-handbookBug hunter handbook focused on web security methodology and recon techniques.
  • pentest-book.comPentesting reference in book format — enumeration, exploitation, post-exploitation.
  • amanhardikar.com/mindmapsMind maps covering practice labs, forensics, and code review. Content is from 2019 but the structural overview is still useful.
  • OWASP Web Security Testing GuideAuthoritative reference for systematic web application security testing methodology.

web application security

  • portswigger.net/web-securityPortSwigger Web Security Academy. Free labs covering OWASP Top 10, SQLi, XSS, SSRF, XXE, deserialization, and an LLM security module. The gold standard for web security practice.
  • hacker101.comHackerOne free training platform with videos and CTF challenges. High scores can earn private bug bounty program invites.
  • hackinghub.ioClosest to real-world pentesting scenarios among web lab platforms. Scenario-driven rather than isolated challenges.
  • pentesterlab.comBadge-based learning organized by vulnerability type (SQLi, XXE, JWT, code review), built on real CVEs.
  • websec.frLogic flaw based challenges. Non-trivial, requires thinking beyond pattern-matching.
  • alf.nu/alert1XSS wargame focused exclusively on bypassing XSS filters.
  • application.securityKontra AppSec: interactive code review training focused on identifying vulnerabilities in source code.

ai / llm security

  • gandalf.lakera.aiProgressive prompt injection challenges designed to extract a secret from a guarded LLM. Good for understanding injection escalation.
  • pentesting.site — LLM methodologyMethodology guide for LLM pentesting. PortSwigger also has a dedicated LLM module.

linux / privilege escalation

  • overthewire.org/wargames/banditSSH-based wargame that drills Linux fundamentals — SUID, cron jobs, file permissions, and misconfiguration exploitation. Best starting point for Linux privilege escalation concepts.
  • cmdchallenge.comBrowser-based shell drills. Pure command-line problem solving without any environment setup.

ctf / wargames

  • root-me.orgLarge multi-category platform (web, crypto, forensics, network, RE) with a well-structured difficulty curve.
  • picoctf.comBeginner-oriented, open year-round. Extensive writeup community.
  • Google CTFAnnual competition. Previous years challenges are publicly available and are high quality.
  • dreamhack.ioOngoing CTF challenges with writeups from challenge authors. Covers pwn and web.
  • OliCyber TrainingItalian national CTF team platform with 2000+ challenges across all levels.
  • SANS Holiday Hack ChallengeAnnual seasonal CTF with a narrative-driven format.

boot2root / vulnerable vms

  • hackmyvm.euDownloadable and online vulnerable machines.
  • vulnyx.com160+ free vulnerable VMs across difficulty levels.
  • dockerlabs.esDocker-based vulnerable environments. Fast to spin up.
  • exploit.educationPhoenix, Fusion, and Nebula VMs for learning binary exploitation in a controlled environment.

binary exploitation / pwn

  • pwn.collegeStructured curriculum from GDB and assembly basics up to kernel exploitation. Best free resource for learning binary exploitation systematically.
  • pwnable.krClassic binary exploitation wargame. Well-known reference challenges.
  • ir0nstone binary exploitation notesWell-written progressive guide covering ret2win, ROP chains, ASLR bypass, heap exploitation.
  • NightmareIntroduction to binary exploitation and reverse engineering through CTF challenges. Covers format strings, heap, ROP, and more.
  • ret2 wargamesBrowser-based exploit development environment.

reverse engineering

  • crackmes.oneLarge archive of crackme binaries across all skill levels and platforms.
  • microcorruption.comEmbedded systems RE challenge using MSP430 assembly with an in-browser debugger.
  • Flare-OnMandiant annual reverse engineering competition. Previous years challenges are among the most rigorous RE exercises publicly accessible.
  • OpenSecurityTraining2University-depth courses on architecture, firmware analysis, and RE. Free.

cryptography

  • cryptohack.orgModern cryptography challenges focused on practical attacks — RSA, ECC, block ciphers.
  • cryptopals.com48 challenges where you break real crypto by implementing the attacks yourself. Covers stream ciphers, CBC padding oracles, hash length extension, and more.

blue team / forensics / dfir

  • cyberdefenders.orgForensics and incident response labs — memory forensics, network analysis, malware triage.
  • kc7cyber.comThreat hunting platform using Azure log queries and IOC pivoting. Scenario-driven SOC analyst training.

bug bounty

  • hackerone.comLeading bug bounty platform. Public and private programs across major companies.
  • bugcrowd.comBugcrowd University: bug hunting methodology training alongside the bounty platform.
  • intigriti.comEuropean bug bounty platform with a built-in learning section (Hackademy).
  • pentester.land/writeupsCurated bug bounty and CTF writeups indexed by vulnerability class.
  • HackerOne HacktivityPublic disclosed bug bounty reports. Excellent for learning real vulnerability chains.

blockchain / smart contract security

  • ethernaut.openzeppelin.comSolidity vulnerability challenges in an OverTheWire-style progression. Covers reentrancy, access control, delegatecall abuse, and more.
  • damnvulnerabledefi.xyzDeFi-specific exploit scenarios including flash loan attacks, price oracle manipulation, and lending protocol exploits.

tools

  • revshells.comReverse shell one-liner generator for all major languages and encodings.
  • stego-toolkitDocker image bundling steganography detection and extraction tools. Useful for CTF stego challenges.
  • PentestToolsCurated collection of pentesting tools organized by category.
