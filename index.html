About

Pentest fókuszú security learner / practitioner. A célom nem “CTF flex”, hanem olyan dokumentáció, ami üzleti környezetben is értelmezhető: attack surface → initial access → privilege escalation → mitigáció.

  • Erősségek: szolgáltatás-felderítés (TCP/UDP), web és network attack chain gondolkodás, Linux privesc.
  • Output: tiszta, reprodukálható writeup + rövid remediation pontok (hardening, least privilege, auth).
  • Fókusz: valós hibaminták (misconfig, weak auth, info leak, unsafe evaluation, trust boundary).
